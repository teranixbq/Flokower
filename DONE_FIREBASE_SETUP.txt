STEP 1: DOWNLOAD FIREBASE CONFIGURATION (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open browser and go to:
   https://console.firebase.google.com/project/flokower/settings/general
   
2. Scroll down to "Your apps" section
3. Click on Android app: com.example.flokower
4. Click button: "Download google-services.json"
5. File will save to your Downloads folder

✅ DONE! File downloaded!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2: MOVE FILE & RUN APP (3 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open terminal and run these commands:

cd ~/Downloads
mv google-services.json ~/Documents/Flokower/android/app/

cd ~/Documents/Flokower
flutter pub get
flutter run

✅ That's it! Your app is connected to Firebase!

❓ TROUBLESHOOTING:

Issue: "No Firebase App found"
Solution: Make sure google-services.json is in android/app/

Issue: "Permission denied"  
Solution: Enable Firestore database first in Firebase Console

Issue: Build fails
Solution: Run flutter clean then flutter pub get again
